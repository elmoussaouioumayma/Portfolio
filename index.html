02 · Projects

Selected work

Master's thesis · Hochschule Aalen · 2026

Optimized Image Processing for Quantitative Crack Analysis in Chromium Layers

An automated Python pipeline that turns microscope images of hard-chromium coatings into crack measurements, replacing manual annotation that took 2 to 2.5 hours per image.

  1. Segment5 classical methods compared; top-hat + Otsu selected
  2. Vectorizeskeleton converted into a crack graph
  3. Measurelength, density and junction angles in µm

Validated against manual ground truth: chamfer distance under 1.77 px (≈ 0.08 µm) on 7 of 8 images. Crack density across 20 images (564 ± 70 cracks/cm) lies within the published range for hard chromium.

  • OpenCV
  • scikit-image
  • graph extraction
  • validation

Image analysis

Coating Layer Analysis

Detects the layers of a coating in cross-section images from changes in particle size and density, traces the wavy boundaries and measures each layer's thickness. The number of layers is chosen with a statistical model (BIC). Includes a web app and a batch tool.

95% correct layer count · 0.66 µm median boundary error (100 test images)
