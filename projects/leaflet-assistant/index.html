How it works

Safety checks first, then retrieval, then a cited answer

EU package leaflets all follow the same template with six numbered sections. The leaflets are split along those sections, so every passage stays on one topic and every answer can say where it came from: "section 4, Possible side effects".

  1. GuardrailsTransparent, tested rules run before anything else. Overdoses, poisoning, breathing problems and self-harm get an emergency message (112). "Should I…" and "is it safe for me…" questions are sent to a pharmacist or doctor.
  2. Medicine checkThe question must name a medicine that is covered. "Side effects of aspirin" is never answered from another medicine's leaflet.
  3. RetrievalTF-IDF on word and character n-grams with light stemming. Patient words for each section ("store", "dose", "side effects") are added to the index, so "how should X be stored" finds section 5.
  4. AbstentionIf the best score is below 0.12, the answer is "not found", not a guess. Passages from other medicines are dropped.
  5. AnswerThe full project sends the passages to any OpenAI-compatible LLM (OpenAI, Azure, local Ollama) with mandatory [n] citations, and falls back to the extractive answer shown here if the LLM fails.
  6. ServingFastAPI with /ask, /health and /metrics, a Gradio UI and Docker. Prometheus tracks requests by outcome, latency and retrieval scores. Logs store only a hash of the question, never the text.

Limitations

  • The test leaflets are fictional and short, so these numbers check that the pipeline works. They do not measure quality on real leaflets.
  • Extractive answers are leaflet sentences, not a written summary. Some questions get a nearby but not exact sentence. The sources panel shows why.
  • The guardrails are keyword rules: transparent and tested, but they will miss some paraphrases. A production system would add a trained classifier and human review.
  • English leaflets only.

Not medical advice

This is a portfolio project, not a medical device. The leaflets in this demo are fictional and written only for testing.
